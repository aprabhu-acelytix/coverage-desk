# Three-minute outlet-first walkthrough

**0:00-0:40 - Client to overview.** Open Coverage Desk > Home > Explore. Select Meta with the Muse AI Agent campaign and past-week period. Use the view selector beside the active-view header. Show Coverage found, reporting article/outlet totals, freshness and partial status. Refresh performs owner-operated discovery and assessment; browsing does not use AI. Explain that this is coverage found, not a complete census.

**0:40-1:20 - Outlet to articles.** Read the full outlet names below the bars. Choose View articles beside an outlet. Compare its count to the source-linked article rows and publication dates. Use Back to overview or Clear outlet. Reporting is separate from company announcements, press-release distribution, sponsored, social and unknown types. Articles outside an outlet selection includes all source types; the overview category selector changes which types are counted.

**1:20-2:00 - Evidence.** Inspect a counted article. Review the retained excerpt, message quotations, publication evidence and source observations. Missing campaign slogans and criticism do not make coverage irrelevant. Use Relevant, Needs attention or All results. Mark relevant records an owner match decision without AI; unknown publication dates remain unverified. Inspect > Edit finding changes one detail at a time. Source details opens with the outlet profile and linked editorial signals; Outlet priority adjusts ordering with a private reason. Source & history filters keeps older scopes inspectable.

**2:00-3:00 - Sharing preview.** Choose Preview & share overview. Read the disclosure of private aggregates and included source information; approve preparation only if appropriate. Review all included sources and the complete frozen outlet breakdown, then return to the exact preview. Stop before Publish unless you intend to send that exact content to #coverage-desk-demo. Final owner confirmation alone posts and shares the frozen snapshot. It appears in Briefings with the correct Draft/Published label. Normal editable briefings and Team board Save/perspectives/deletion remain available.

Required visual checks on the owner's Slack client: light and dark mode; narrow width; zero chart baseline and numeric values; long outlet labels/full-name correspondence; outlet and source pagination; detail-modal spacing; empty/partial states; disclosure and preview navigation. No connected browser was available during implementation, so these checks remain unverified. Fixture tests and API payload acceptance do not substitute for visual or real multi-user evidence.

Local backend: `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/backend.ps1 status` (replace status with start, stop or restart). Keep the Windows host running. This is one local Socket Mode process, not cloud hosting.
